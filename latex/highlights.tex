\section*{Highlights}

\begin{itemize}
\item Bridge exploits are replayed in two linked Ethereum Virtual Machines and a relay.
\item An oracle built from generated text flagged all 12 fixtures even when no code ran.
\item A valid exploit needs executed transfers, replay, and no gain on a patched copy.
\item Nomad, Qubit: all vulnerable runs found valid exploits; no patched run alerted.
\item Retrieval-generated seeds were not consistently faster than random seeds.
\end{itemize}
