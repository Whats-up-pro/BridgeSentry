\section*{Highlights}

\begin{itemize}
\item A valid bridge exploit needs executed gain, replay, and no gain on patched code.
\item An oracle built from generated text flagged all 12 incidents without running code.
\item Seven incidents, four crossing a relay: no alert in 940 patched-variant runs.
\item LLM seeds without the target's code in the prompt did not beat random seeds.
\item LLM seeds from comment-free code solved all 400 runs, even without retrieval.
\end{itemize}
